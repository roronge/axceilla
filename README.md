# Axceilla Shop

Katalog pakaian bayi dan anak dengan tampilan showroom gantungan.

## Jalankan
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Tampilan katalog
- Satu batang gantungan horizontal lurus warna rose-gold.
- Pakaian tampil dari hanger masing-masing; tidak ada rangka kotak atau kaki samping.
- Background showroom cream / dusty pink.
- Klik pakaian untuk membuka detail, pilihan ukuran, tampilan depan/belakang, dan keranjang.
- Foto contoh sisi belakang sudah dibersihkan dari pola checkerboard dan disimpan dengan transparansi.

## Admin
Buka `/admin`. PIN demo: `AXCEILLA2026`.
Katalog demo menggunakan Local Storage. Versi penyimpanan baru akan memigrasikan data lama dan memperbarui foto produk contoh.
